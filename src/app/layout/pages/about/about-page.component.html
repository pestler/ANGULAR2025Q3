Smart Home UI is a modern web application for managing and monitoring smart devices in a residential environment. It features a responsive and modular interface designed to deliver real-time insights and intuitive control across various device configurations.

🔧 Key Features

  • 📊 Monitor temperature, humidity, weather conditions, and electricity usage
  • 💡 Control lights, sockets, relays, and switches with instant feedback
  • 🧩 Access a unified dashboard with device and sensor cards grouped by rooms or zones
  • 🛠️ Adapt the layout to match diverse room setups and hardware combinations
  • ⚡ Receive real-time status updates from connected devices

🧠 Architecture

The application is built with Angular 20, leveraging:

  • ✅ Standalone components and signal-based state management
  • ✅ Modular routing and layered architecture
  • ✅ ESLint-compliant patterns and developer experience best practices

Smart Home UI serves as a reference implementation for scalable, maintainable frontend systems, ideal for team onboarding and architectural learning.

🎓 Educational Context

This project is developed as part of the RS School educational program and showcases modern frontend engineering principles in practice.
