# Smart Home UI

This project is an implementation of a Smart Home UI using Angular. It is a task from the Rolling Scopes School.

The project is divided into three parts:
- [Part 1: Smart Home UI](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/angular-smart-home-ui/smart-home-part-1.md)
- [Part 2: Smart Home UI](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/angular-smart-home-ui/smart-home-part-2.md)
- [Part 3: Smart Home UI](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/angular-smart-home-ui/smart-home-part-3.md)

## Features

- Dashboard with smart home devices
- Control and monitor devices
- Theme switching (light/dark)
